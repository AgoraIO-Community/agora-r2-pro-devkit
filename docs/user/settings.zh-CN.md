# 设置、设备配网与关机

主界面右上角的齿轮打开设置页，包含“设备配网”和“关机”，左上角“返回”关闭设置页。关机失败页同样在左上角返回。设置使用独立的产品输入服务，从 UI 就绪后即可操作，在等待网络、AP 配网和首次绑定期间也可使用。菜单打开时的触摸不会开始或结束对话。

手动配网仅通过设置页中的“设备配网”进入。点击后会关闭设置页；如果业务正在运行，应用先结束会话并释放 SDK，再进入现有 AP 配网流程。手机连接屏幕显示的热点并访问 `http://192.168.4.1/`，完成后恢复原有绑定和业务。已经处于配网状态时返回现有配网指引。步骤见[配网指南](wifi-provisioning.zh-CN.md)。配置显式禁用 Wi-Fi 配网时，此操作不会开启 AP。

点击“关机”先显示二次确认；“取消”返回设置页，“确认关机”才进入“正在关机”。设置页关闭后，屏幕短触或 Menu 短按可切换会话；长按触屏或 Menu 键不会启动会话或配网。设置页打开时 ESC 返回，关机确认页也可用 ESC 取消。

受监督服务收到已确认请求后，验证请求来自自己的应用子进程；应用正常结束 SDK、AP、提示音、音视频、输入及显示，再退出。监督器确认自有后代已回收后同步存储并通过系统正常 `poweroff` 关机，不使用强制断电。崩溃、非零退出或清理超时会阻止该关机动作，并保留故障状态供排查。

该关机入口需要使用部署安装的 `/etc/init.d/S99mybot` 服务。手动执行 `run.sh` 时没有监督服务的关机授权，会显示关机失败并保留程序运行；可返回设置后继续使用。服务操作见[部署指南](deployment.zh-CN.md)。

当前板卡的 RK805 配置为系统电源控制器，但 PMIC 电源键节点为 disabled。关机后是否可按键开机、USB 供电下哪些部件仍带电，需要按实际硬件验证，不能从软件退出推断整板完全断电。需要恢复电源时按板卡供电方式操作。

验证时先检查：等待网络和 ready 均可打开设置；点击齿轮不触发会话；关机取消不影响业务；配网完成恢复 ready；最后在方便重新上电时测试确认关机。本轮代理使用记录标记的模拟关机程序验证完整清理，不主动执行真实断电。实际证据见[验证状态](../validation/README.md)。
