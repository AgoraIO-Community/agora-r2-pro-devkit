# 1.0.0 验证

以下是 2026-11-20 对应用 1.0.0 的既有验收记录。目标板为 RV1126B TEST2 RK805B V10。

| 范围 | 结果 |
| --- | --- |
| Ubuntu 24.04.4 | GCC 13.3 构建通过。中文、英文、UBSan 三套 CTest 各通过 28/28 项，每套包含同一组 230 项 Python 工具测试。固定依赖校验通过，两份 25 页操作手册均可重现。 |
| AArch64 制品 | 中英文各完成语音和视频构建。应用、监督器、恢复出厂工具的 ABI 检查通过。两个归档各有 71 项内部文件校验，重复打包生成相同字节。 |
| 中文视频设备 | 从 0.6.1 升级，服务重启和整机重启均恢复到 `ready`。一次整机重启耗时约 24.9 秒。Wi-Fi 状态从等待进入联网，失败记录和热点提示均为零。 |
| 操作及持久化 | 触摸事件注入验证设置页进入和返回。绑定及系统 Wi-Fi 配置与升级前备份逐字节一致，两个已存网络保留。设备保留 0.6.1 供回退。 |

本轮设备验收覆盖中文视频程序的启动、网络及设置入口。真实通话与 AEC、云端视频收帧、手机配网、物理关机、实际恢复出厂及长时间运行属于单独验收范围。

构建和测试方法见[测试指南](../development/testing.zh-CN.md)，打包步骤见[发布指南](../development/releasing.zh-CN.md)。

## 官方版本的本地验证

Ubuntu 上的中文、英文和 UBSan 主机构建各通过 27 项原生 CTest，230 项 Python 工具测试通过。依赖锁、质量检查和两份双语操作手册的字节重现检查通过。本次验证限于主机环境。
